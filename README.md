# Tabajoy Stitch Project

Google Stitch design sources and a curated, browse-only static prototype for the Tabajoy Japanese DTC storefront concept.

## Project structure

- `design-source/sitemap/code.html` — current 26-screen inventory and prototype status.
- `design-source/screens/` — authoritative Stitch HTML sources organized by page and viewport.
- `design-source/design-system/DESIGN.md` — Tabajoy visual direction and design tokens.
- `vercel-prototype/` — curated static pages prepared for Vercel deployment.

Superseded iterations and canvas preview screenshots were removed. The prototype uses remote product image URLs and external font/Tailwind resources; the exported screen previews were not product assets.

## Prototype status

This is not a production shop. Product prices and operational details remain unconfirmed; Medusa and Stripe are not connected, and no orders or payments can be submitted. See [`vercel-prototype/DEPLOY.md`](vercel-prototype/DEPLOY.md) for deployment notes.
