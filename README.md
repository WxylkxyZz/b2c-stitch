# Tabajoy Stitch Export

Google Stitch screen export for the Tabajoy Japanese DTC storefront concept.

- `00_sitemap_tabajoy/` contains the current page inventory and prototype status.
- `vercel-prototype/` contains the curated, browse-only static prototype for Vercel.
- Other screen folders preserve the full Stitch export, including earlier iterations and preview screenshots.

The Vercel prototype is not a production shop. Product prices and operational details remain unconfirmed; Medusa and Stripe are not connected, and no orders or payments can be submitted. See [`vercel-prototype/DEPLOY.md`](vercel-prototype/DEPLOY.md) for deployment notes.
